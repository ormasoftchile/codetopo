\section{MCP Protocol}
\label{sec:mcp-protocol}

\subsection{Background}

The Model Context Protocol~\cite{anthropic2024mcp} is an open JSON-RPC~2.0
protocol, inspired by the Language Server Protocol~\cite{microsoft2016lsp},
designed for connecting LLM applications to external data sources and tools.
Like LSP, it runs over stdio with newline-delimited JSON messages. Unlike LSP
(which is editor-to-language-server), MCP is agent-to-tool-server: the
client is an LLM or AI agent, and the server exposes \emph{tools} --- named
callable operations with typed input schemas.

\subsection{Why MCP for code intelligence}

The tool-call pattern maps naturally to code intelligence queries. An AI agent
can call \texttt{symbol\_search} as naturally as it calls any other function.
The structured JSON input/output means the agent never needs to parse
grep-style output or interpret editor hover text. codetopo registers 41 tools
that cover the full range of structural queries an AI agent needs when
working on a codebase.

\subsection{Transport and framing}

\begin{itemize}
  \item Transport: stdio (one server process per client session).
  \item Framing: newline-delimited JSON (NDJSON); each message is a UTF-8
        JSON object terminated by \verb|\n|.
  \item Protocol version: \texttt{2024-11-05}\footnote{MCP protocol versions
        use calendar-date strings. \texttt{2024-11-05} is the version at which
        the core tool-call, prompts, and resources primitives were stabilized
        in the initial public specification.} (returned in the handshake
        \texttt{initialize} response).
\end{itemize}

\subsection{Connection lifecycle}

\begin{enumerate}
  \item Client sends \texttt{initialize} with protocol version and
        client capabilities.
  \item Server responds with \texttt{protocolVersion}, server info, and the
        full tool list.
  \item Client sends \texttt{initialized} notification.
  \item Client sends \texttt{tools/call} requests; server responds with results.
  \item Either side may send \texttt{shutdown} to end the session.
\end{enumerate}

\subsection{Staleness detection}

Each tool response includes a \texttt{\_meta} object. When the server detects
that the index may be out of date --- by checking the mtime of
\texttt{.git/HEAD} against the timestamp of the last index run --- it sets
\texttt{\_meta.stale = true}. Clients should treat stale responses as advisory:
the data is the last known good state, but a call to \texttt{reindex} is
recommended.

\subsection{QueryCache}
\label{sec:querycache}

The \texttt{QueryCache} is an in-process prepared-statement cache keyed by
tool name. Preparing a SQLite statement compiles it to bytecode; caching avoids
re-compilation on every tool call. The cache is cleared (all statements
finalized) at the start of each re-index cycle so that schema changes take
effect immediately.

\subsection{Tool catalogue}

The 41 tools are organized into nine categories.

\subsubsection{Navigation}

\begin{description}
  \item[\texttt{dir\_list}] List files and directories under a path.
  \item[\texttt{dir\_tree}] Return full directory subtree up to depth $N$ with
        file sizes and language classification.
  \item[\texttt{file\_search}] Find files by path pattern (GLOB syntax) across all roots.
  \item[\texttt{file\_summary}] Return symbol-annotated outline of a file.
  \item[\texttt{file\_overview}] Return structural overview of top-level symbols,
        signatures, and doc comments for a file without loading bodies.
  \item[\texttt{source\_at}] Read raw source content for a given line range.
\end{description}

\subsubsection{Symbol lookup}

\begin{description}
  \item[\texttt{symbol\_search}] FTS5 prefix and ranked search over symbol names,
        qualified names, signatures, and docstrings. Supports stable keys and
        kind filtering.
  \item[\texttt{symbol\_list}] List and filter symbols in a root or file without
        full-text search, with listing-safe payload pruning.
  \item[\texttt{symbols\_in\_path}] Enumerate symbols under a directory path with
        listing-safe filtering and candidate metrics.
  \item[\texttt{symbol\_get}] Fetch detailed symbol information and source code
        by reindex-proof \texttt{stable\_key} or \texttt{node\_id}.
  \item[\texttt{symbol\_get\_batch}] Fetch multiple symbols by ID in one
        round-trip.
  \item[\texttt{context\_by\_name}] Look up a symbol by name and return its full
        structural context, or a disambiguation list if ambiguous.
\end{description}

\subsubsection{Graph traversal}

\begin{description}
  \item[\texttt{callers\_approx}] Direct callers of a symbol (inbound
        \texttt{calls} edges). Named ``approx'' because call edges are
        AST-derived without full type resolution; includes fallback candidate
        resolution and receiver type filtering.
  \item[\texttt{callees\_approx}] Direct callees of a symbol (outbound
        \texttt{calls} edges), including unresolved name-only entries.
  \item[\texttt{references}] All reference sites for a symbol across all roots.
  \item[\texttt{context\_for}] Return the full structural context of a symbol
        (definition, source, exact callers/callees, container, siblings, bases).
  \item[\texttt{entrypoints}] Identify symbols with no callers (potential
        entry points or public APIs).
\end{description}

\subsubsection{Impact and change analysis}

\begin{description}
  \item[\texttt{impact\_of}] Transitive BFS/DFS blast radius over the call
        graph from a seed node up to depth $N$.
  \item[\texttt{detect\_changes}] PR blast-radius analysis: maps \texttt{git diff}
        changes against a base ref to AST symbols, then BFS-traverses reverse
        call edges to find impacted callers.
  \item[\texttt{subgraph}] Extract the dependency neighborhood graph reachable
        from a set of seed nodes up to a given depth.
  \item[\texttt{shortest\_path}] Find the shortest call path between two
        symbols using BFS.
  \item[\texttt{find\_similar}] Find near-duplicate functions or methods using
        MinHash fingerprints of normalized AST leaf trigrams.
\end{description}

\subsubsection{Architecture and coupling}

\begin{description}
  \item[\texttt{get\_architecture}] Summarize repository architecture from the
        indexed graph, identifying directory clusters, hotspots, boundaries,
        and cohesion/coupling metrics.
  \item[\texttt{dependency\_cluster}] Group methods in a file or class by
        shared field access patterns, computing extractability scores for
        refactoring decomposition.
  \item[\texttt{find\_implementations}] Find concrete implementations or
        subtypes of an interface, trait, or abstract class.
  \item[\texttt{file\_deps}] Return the import/include dependency graph for a
        file.
  \item[\texttt{method\_fields}] List the fields accessed by a method and
        distinguish local versus external calls.
\end{description}

\subsubsection{Distributed tracing and telemetry}

\begin{description}
  \item[\texttt{list\_http\_calls}] Inspect protocol-aware HTTP client call
        references and target endpoint paths captured during indexing.
  \item[\texttt{ingest\_traces}] Ingest observed runtime call traces (e.g., from
        OpenTelemetry) with call counts and latency percentiles to boost static
        call-graph confidence scores.
  \item[\texttt{get\_traces}] Query ingested runtime traces and evaluate their
        resolution status against indexed static symbols and call edges.
\end{description}

\subsubsection{Full-text search}

\begin{description}
  \item[\texttt{code\_search}] Trigram full-text search over source lines
        using the \texttt{content\_fts} contentless FTS5 index~\cite{cox2012trigram}.
        Returns matching lines with file path and line number.
\end{description}

\subsubsection{Workspace management}

\begin{description}
  \item[\texttt{workspace\_add}] Start an asynchronous background job to index
        and merge an extra repository root into the shared workspace.
  \item[\texttt{workspace\_remove}] Start an asynchronous job to remove an extra
        root and cascade-delete its rows.
  \item[\texttt{workspace\_list}] List all registered roots with symbol, file,
        and edge counts.
  \item[\texttt{workspace\_refresh}] Start an asynchronous background re-index of
        changed files within an extra root.
  \item[\texttt{workspace\_job\_status}] Query the retained status, phase, and
        elapsed time of an active or recent workspace job.
  \item[\texttt{workspace\_job\_cancel}] Request graceful cancellation of an
        asynchronous workspace job at the next safe phase boundary.
\end{description}

\subsubsection{Server lifecycle and diagnostics}

\begin{description}
  \item[\texttt{server\_info}] Server version, protocol version, schema version,
        and supported languages.
  \item[\texttt{server\_health}] In-memory readiness and liveness probe for
        client orchestration.
  \item[\texttt{repo\_stats}] Metadata summary, row counts, language
        distribution, and index size without slow graph scans.
  \item[\texttt{reindex}] Trigger an incremental or full background re-index of
        the repository.
\end{description}
