\section{Status}
\label{sec:status}

\subsection{Implemented}

The following capabilities are implemented, tested, and functional in production:

\begin{itemize}
  \item \textbf{Continuous graph synchronization:} Two-tier change detection
        (\texttt{mtime\_ns} and \texttt{size\_bytes} stat fast path, \texttt{xxHash64}
        content fingerprinting), platform-native watchers (\texttt{FSEvents},
        \texttt{inotify}, \texttt{ReadDirectoryChangesW}), 1\,000\,ms debouncing,
        and thread-safe in-flight change coalescing (\texttt{ReindexState}).
  \item \textbf{Targeted symbol attraction:} Incremental graph maintenance
        isolating affected references across unmodified files via pinned temporary
        tables (\texttt{\_\_ct\_affected}, \texttt{\_\_ct\_defnames}) and
        \texttt{CROSS JOIN} query ordering, bounding updates to
        $O(|\mathcal{D}_{\text{changed}}| \cdot \bar{d})$.
  \item \textbf{Polyglot structural AST extraction:} Tree-sitter parsing for
        13 languages (C, C++, C\#, TypeScript, JavaScript, Python, Rust, Java,
        Go, Bash, SQL, YAML, and Lua) extracting definitions, calls, imports,
        inheritance, and structural containment edges.
  \item \textbf{Static and runtime topology:} Dual-layer graph integrating
        static AST relations with distributed trace ingestion (\texttt{ingest\_traces},
        \texttt{get\_traces}) and protocol-aware HTTP call extraction
        (\texttt{list\_http\_calls}).
  \item \textbf{Graph centrality ranking:} Structural PageRank power iteration
        over directed edges persisted in \texttt{nodes.rank} (schema v14) with
        covering partial index \texttt{idx\_\allowbreak nodes\_\allowbreak rank}, boosting symbol search
        and accelerating entrypoint identification.
  \item \textbf{MCP protocol surface:} All 41 MCP tools registered and functional
        (31 code intelligence, 6 multi-root workspace management, and 4 server operations
        and diagnostics).
  \item \textbf{PR blast-radius analysis:} \texttt{detect\_changes} integrating
        \texttt{git diff} against base refs with reverse call-graph BFS traversals.
  \item \textbf{Architecture summarization:} \texttt{get\_architecture} computing
        directory clusters, hotspot rankings, subsystem boundaries, and coupling/cohesion metrics.
  \item \textbf{Multi-root workspaces:} Single-database multi-root management with
        multiplicative ID offset scheme ($10^9$ namespace allocation) and cascade removal.
  \item \textbf{C++26 systems runtime:} Pack-indexed variadic SQLite statement
        binding (\texttt{db::bind}), arena memory pooling, and zero-heap
        \texttt{std::inplace\_vector<T, N>} container polyfills on hot paths.
  \item \textbf{Concurrency and persistence:} Concurrent reader-writer snapshot isolation
        via SQLite WAL mode, PID-based process mutual exclusion (\texttt{FileLock})
        with stale-lock recovery, and generation-tracked prepared-statement cache (\texttt{QueryCache}).
  \item \textbf{Graph-quality and correctness metrics:} Quantifying resolution rates,
        ambiguity counts, dangling references, and confidence distributions by language
        and edge kind via CLI (\texttt{codetopo quality}) and MCP endpoints.
  \item \textbf{Explicit edge provenance model:} Schema~v15 evidence tracking distinguishing
        edge sources (\texttt{static}, \texttt{semantic}, \texttt{runtime}, \texttt{protocol},
        \texttt{inferred}) alongside observation counts and timestamps.
  \item \textbf{Semantic graph diff:} Change analysis extending from Git file diffs to
        topology diffs (\texttt{codetopo diff}), reporting added/removed symbols, modified
        signatures, edge shifts, and subsystem coupling deltas.
  \item \textbf{Durable stable symbol identity:} In-place UPSERT tracking that
        maintains durable \texttt{node\_id} identity across line movements, refactorings, and file edits.
\end{itemize}

\subsection{Known limitations}

\begin{itemize}
  \item \textbf{Approximate call edges.} Cross-file call resolution is AST-derived without
        deep type inference. Overloaded functions and virtual dispatch are flagged as approximate
        (\texttt{confidence < 1.0}).
  \item \textbf{Incremental centrality maintenance.} Global PageRank is calculated during initial
        indexing and workspace merges; localized incremental centrality updates during single-file
        edits are deferred to avoid blocking file-watcher debouncing.
  \item \textbf{No dataflow or taint analysis.} CodeTopo models structural and architectural
        dependencies, not register-level dataflow or variable taint propagation.
  \item \textbf{Local single-binary architecture.} The index is designed for zero-dependency local
        operation; distributed multi-tenant server infrastructure is intentionally excluded to
        preserve privacy, predictability, and sub-millisecond local query latencies.
\end{itemize}
